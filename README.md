# Food Ordering System 🍽️

## 📌 Overview
A **full-stack food ordering system** with a **Node.js + Express backend** and a **static frontend built using HTML and CSS**.  
The backend provides REST APIs and handles authentication, while the frontend offers a simple user interface.

---

## 🛠️ Tech Stack

### Backend
- Node.js
- Express.js
- MySQL
- bcryptjs (password hashing)
- express-session
- dotenv
- cors

### Frontend
- HTML5
- CSS3
- Static files served using Express (`public/` folder)

---

## 🚀 Features
- User registration and login
- Secure password hashing
- Session-based authentication
- MySQL database integration
- Static frontend UI (HTML + CSS)
- Clean, modular backend architecture
- Separation of concerns (routes, controllers, config)
